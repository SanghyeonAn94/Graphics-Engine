## 사용 예제 패턴

### 이벤트 발생
```cpp
// 매크로 사용
ENGINE_EMIT_EVENT(PlayerDamagedEvent, playerId, damage, attackerName);

// 직접 호출
EventSystem::emit<KeyEvent>(keyCode, KeyEvent::Action::Press);

// 우선순위 지정
EventSystem::emitQueued<WindowResizeEvent>(EventPriority::High, width, height);
```

### 이벤트 리스닝
```cpp
// 람다 리스너
auto listener = EventSystem::listen<PlayerDamagedEvent>([](const PlayerDamagedEvent& event) {
    // 처리 로직
});

// RAII 스코프 리스너
ENGINE_SCOPED_LISTEN(GameStateChangedEvent, [](const GameStateChangedEvent& event) {
    // 스코프 벗어나면 자동 해제
});
```

### 스케줄된 이벤트
```cpp
// 지연 실행
g_eventScheduler.scheduleEvent<MyEvent>(std::chrono::milliseconds(1000), 
                                       EventPriority::Normal, eventData);

// 반복 실행
g_eventScheduler.scheduleRecurring<HeartbeatEvent>(std::chrono::seconds(1),
                                                  EventPriority::Background);
```
