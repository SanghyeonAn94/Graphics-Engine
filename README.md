# Graphics-Engine

A project for learning game engine development.

## Project Structure

- **Engine/**: Actual implemented game engine code
- **Lectures/**: Explanations and learning materials for the implemented code
- **References/**: Open source projects for reference
  - **Renderers/**: Rendering-related reference projects
- **Docs/**: Project documentation
  - **standards.md**: Coding standards and best practices

## Purpose

The goal is to analyze and learn from various reference codes to ultimately implement a complete game engine.

## Getting Started

Before contributing to this project, please read our [Coding Standards](docs/standards.md) to ensure consistency across the codebase.
